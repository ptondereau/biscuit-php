# Security Policy

This repository is a read-only mirror of [ptondereau/biscuit-php](https://github.com/ptondereau/biscuit-php).

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests. Follow the [biscuit-php security policy](https://github.com/ptondereau/biscuit-php/blob/main/SECURITY.md) and report them through [GitHub Private Vulnerability Reporting](https://github.com/ptondereau/biscuit-php/security/advisories/new).
